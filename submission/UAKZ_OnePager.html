1. Challenge tackled

Problem: what makes an experienced employee good is never written down. Screen recordings show what was clicked, not why, and limits ("equipment over 5,000 EUR is always capex") stay invisible until someone breaks them. Users: the expert (an accounts-payable clerk), the new hire who must take over, and a software agent that must stop where the expert would.

What we built: three modules on one sandbox ERP with fake invoices. Capture: the expert shares a screen and works while talking; a voice agent asks why only when the screen is still and the expert is quiet, at least three questions, one about a guardrail. Map: spoken debrief with follow-ups, then a teach-back the expert confirms, producing a Work Map (every step = decision + reason in the expert's verbatim words + guardrails + screen moment). Teach: a voice tutor explains each step, has the new hire predict the next decision, and on an unseen EUR 7,200 invoice stops a wrong save before it happens.

3. What worked well

  • 157 / 157 tests pass (node:test) across all three modules.
  • Unseen case caught: live call to the real model flagged cost center 4711 on the unseen EUR 7,200 invoice and quoted the expert's words.
  • Agent hand-off: an agent holding only the exported instructions stopped and asked the controller (no asset number). node scripts/verify-export.js prints PASS.
  • No invented reasons: a quote is kept only if it appears in what the expert said; otherwise it is dropped and counted.
  • Voice round trip: ElevenLabs TTS then Scribe returned the exact sentence.
  • Trust: off-the-record button, masked frames, and the expert can delete any step or answer afterwards; exports no longer contain it.

4. What was challenging

  • When to speak. Two signals must agree: Scribe says the expert stopped talking and a 128x72 pixel probe says the screen is still (2.5 s / 1.8 s). Early versions asked too many generic questions; now capped at 2 per segment, 5 per 10 min, ranked guardrail first.
  • Grounding. LLMs invent plausible reasons. We reject any quote not found verbatim in the expert's speech.
  • "Before it is saved". Screen checks lag, so the sandbox Save asks the open tutor first and stays unsaved on a violation.
  • Privacy. Regex for speech, region and OCR masking for frames; if masking fails the frame is withheld.
  • Environment. An Anthropic key without a workspace id made every call fail with 400; a misspelled env var silently disabled voice.

Honest limits and next steps

Not done: no full rehearsal with real voice and a shared screen yet, so pause latency and questions per 10 min are not measured; the sample Work Map is hand-written; the guardrail MCP tool is not registered on the tutor; names and addresses on screen are not detected and the recorded video file is not redacted. If we had 24 more hours, we would record a real expert session on the sandbox as the sample, run the two-person rehearsal and publish the measured numbers, and add Presidio-grade redaction.

Moonshot: people first, then agents. The same Work Map teaches a new hire today and constrains an AI agent tomorrow. Data: none beyond fake sandbox invoices (public/sandbox/).
